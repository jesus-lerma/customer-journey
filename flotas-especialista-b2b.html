Journey del especialista de flotas

Flujo comercial B2B desde que BDC asigna una oportunidad calificada hasta cierre, entrega y activación de renovación.

Punto de entrada: Asignado

Este flujo empieza cuando el especialista recibe una oportunidad calificada. El objetivo es que no vuelva a perfilar desde cero, sino que avance con contexto, SLA y siguientes pasos claros.

Mensaje Fases Flujo Campos Transversales Salidas
Mensaje central

Después de Asignado empieza el journey comercial de flotas

BDC entrega una oportunidad calificada. El especialista ya no debe reprocesar desde cero: debe diagnosticar, validar solución, cotizar, negociar y cerrar con trazabilidad.

Lo que recibe el especialista

Contexto mínimo para tomar gestión

Empresa, contactos, unidades, necesidad, fecha objetivo, modelos de interés, tipo de compra, fuente B2B, score de calificación y resumen BDC.

Lo que se debe operar

Gestión -> inventario -> cotización -> cierre

El CRM B2B debe sostener la gestión end to end, incluyendo inventario, propuesta, documentación, pedido, facturación, entrega y medición de performance.

Fases del journey comercial

Las fases ayudan a explicar que no todo es cotización: primero se toma gestión, luego se valida solución, después se formaliza y finalmente se cierra.

Capacidades transversales

Son procesos que atraviesan varias etapas y que conviene modelar sin forzarlos como pasos lineales.

Inventario y reserva Diagnóstico -> Pedido

Debe permitir visibilidad y tiempos de respuesta rápidos para evitar cotizar unidades no disponibles.

Financiamiento / leasing Propuesta -> Cierre

Puede ser parte de la solución, no solo un trámite posterior.

Documentación empresarial Aprobación -> Facturación

Bloquea el avance si faltan documentos fiscales, legales o financieros.

Performance del especialista End to end

Mide tiempos, cotizaciones, ratio de cierre, razones de pérdida y unidades ganadas.

Salidas alternas

Estas salidas evitan que todo se convierta en “cerrado” o “pendiente”. Ayudan a medir calidad y a recuperar oportunidades futuras.
